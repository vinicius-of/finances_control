# Dashboard de investimento

Um serviço leve para controle e categorização de finanças. O usuário terá controle e visualização das finanças e investimentos que ele desejar, somente precisando dos dados e o tipo.

O aplicativo consistirá de 3 seções:

- Investimento do tesouro direto;
- Renda fixa
- Ações

Cada seção terá sua lista com investimentos, seus históricos e menu de ações.

A lista de investimento será composta por uma tabela.
Cada tabela vai ter colunas representando os dados dos investimentos dependendo do tipo de investimento.

Cada linha vai representar um investimento com seus respectivos dados.
Cada investimento terá ações permitidas como:

- Atualizar
- Arquivar

## Investimento

Todo investimento terá:
- nome
- tipo
- valor
- data de compra
- data de criação
- data de atualização
- rendimento

O tipo de investimento vai determinar outros atributos.

## Tipos de investimentos

- Tesouro Direto
- Renda Fixa
- Ações
